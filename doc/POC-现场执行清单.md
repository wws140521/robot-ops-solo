## 三、15 分钟出数据 SOP

### ⏱ 分钟 0–2：接线 + 通电

1. 网关盒子接 12V 电源 → 绿灯亮
2. 网线一端插 FANUC 控制器 **Port 2（CD38A，第二个 RJ45 口）**
3. 网线另一端插网关盒子 **LAN 口**
4. 网关 WAN 口用网线接工厂交换机（或连工厂 Wi-Fi）

### ⏱ 分钟 2–5：进网关配置页

1. Mac 连工厂 Wi-Fi（或网关默认热点，如 `WG585-xxxx`）
2. 浏览器打开 `http://192.168.1.1`（网关默认 IP，具体看说明书）
3. 登录（默认 admin/admin）
4. 确认左侧菜单有 **"数据采集"** 或 **"通道管理"**

### ⏱ 分钟 5–8：配 FANUC FOCAS 通道

1. 新建通道 → 选协议 **FANUC FOCAS**
2. 填机器人 IP：`192.168.1.100`（按实际改）
3. 端口：`8193`
4. 测试连接 → 显示"连接成功" ✅
5. 选采集变量：报警码、R 寄存器 100–112（温度/负载）
6. 采集周期：5000ms（5 秒）

### ⏱ 分钟 8–10：配 MQTT 转发

1. 数据转发 → 选 **MQTT**
2. Broker 地址：填你云端 MQTT 地址（或 Mac 本地 `192.168.1.x:1883`）
3. Topic：`roboticsops/telemetry`
4. JSON 格式：选"自定义模板" → 粘贴 UDM JSON 模板（见附录）
5. 保存 → 启用

### ⏱ 分钟 10–12：启动前端

1. Mac 打开终端：`cd ~/Desktop/robot-ops-solo && pnpm dev`
2. 浏览器打开 http://localhost:5173
3. 打开 DevTools → Console → 看到 `[mqtt-client] ✅ connected`

### ⏱ 分钟 12–15：让厂长来看

1. 指着屏幕："王厂长，这是您那台 FANUC M-20iD 的实时数据"
2. 关节负载、温度、告警码全部在动
3. 指着一条告警："您看，2 轴温度 67°C，系统已经标黄预警了"
4. 厂长眼睛亮了 → 进入话术环节

## 四、跟厂长的话术

### 开场白（接线时自然说）

> "王厂长，今天我不碰您任何机器人程序，不断生产，纯旁路接一根网线。
> 数据只在您厂里流转，不出车间，您放心。"

### 常见质疑 + 回答

| 厂长问 | 你怎么答 |
|--------|---------|
| "这不会影响机器人运行吧？" | "不会。只读不写，就像拿听诊器听心跳，不碰机器。" |
| "我们数据不能出工厂。" | "可以。盒子数据只推到您内网的服务器，不出厂门。" |
| "你们跟原厂系统比怎么样？" | "原厂只管一台机器人，我这套把 FANUC、KUKA、安川全接进来，一个屏看所有。" |
| "以后要加机器人怎么办？" | "再接一根网线就行，平台已经做好了，不用重新开发。" |
| "多少钱？" | "首年 ¥5.4 万，含硬件 + 平台 + 告警推送。您这条线停一次机损失多少？" |
| "你这数据准不准？" | "直接从控制器寄存器读，跟示教器上看到的一模一样。" |

### 临门一脚

> "王厂长，今天数据您也看到了。我回去出一份**您这条线的健康报告**，里面会标出哪台机器人哪个关节最容易出问题、建议什么时候保养。您看完觉得有用，我们再谈合作；没用，这 2 周免费试用您也不亏。"

## 五、应急预案（8 种意外）

| # | 意外情况 | 处理方案 |
|---|---------|---------|
| 1 | 机器人控制器没有多余网口 | 用交换机旁路分出来，或接 Port 1（需确认不影响原网络） |
| 2 | 机器人 IP 不知道 | 让操作员进示教器：MENU → SETUP → Host Comm → TCP/IP，查 IP |
| 3 | FOCAS 端口 8193 连不上 | 换 HTTP Data Server 方式（FANUC 内置，免费，不用 FOCAS 库） |
| 4 | 网关连不上工厂 Wi-Fi | 用手机热点；或网关插 4G 卡；或直连 Mac 开的热点 |
| 5 | 前端打不开 / MQTT 连不上 | 切回 mock 模式：`python fanuc_mock.py` 本地发数据，演示不受影响 |
| 6 | 厂长说"今天没空" | 留设备 + 留说明书 + 加微信："那我先留着跑 2 天，数据出来了发您微信" |
| 7 | 机器人正在生产不能停 | 接线 5 分钟，不断电不断网，完全不影响生产，强调"旁路只读" |
| 8 | 网关配置页面打不开 | 重置网关（长按 Reset 5 秒），用默认 IP 重连 |
